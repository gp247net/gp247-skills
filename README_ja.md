# GP247 のエージェントスキル（gp247-skills）

## はじめに

これは GP247 のエージェントスキル（`SKILL.md`）をまとめた共通リポジトリです。このページは**目次**です。
リポジトリ内のすべてのスキルを一覧にし、各スキルへのリンクを載せています。すべてのスキルは GP247 の
スキル標準（`247-skill`）に従っています。内容は英語で書かれ、必須の起動用 `description` と、
更新日時を含むスキル情報ブロックを持ちます。

## スキルは core のバージョンを自動で判別します

スキルは gp247/core のバージョンを**固定で書きません**。各スキルの最初のステップでは、読み取り専用のスクリプト
`scripts/gp247-probe.php` をサイト上で直接実行します。

```bash
php <skill-dir>/scripts/gp247-probe.php
```

スクリプトは次の内容を含む JSON オブジェクトを出力します。

- core が拡張機能の互換性を確認するときと**まったく同じ**core のバージョン（`config('gp247.core')`）と、
  `gp247.json` に書くべき `requireCore` の値
- `gp247/front`、`gp247/shop` が使えるかどうか — ソースコード**と**データベースのテーブルの両方で判断
- サイトで使える `gp247:*` コマンドの一覧
- core／front／shop が現在持っている機能（機能、差し込みポイント）

スキルはこの結果に応じて処理を分けます。そのため、同じスキルをどの core バージョンでも使えます。core のバージョンが
上がるたびに古くなることもありません。各スキルは単体でインストールしても動くように、スクリプトの**まったく同じ**
コピーを持っています。スクリプトを修正するときは、すべてのコピーを修正してください。
